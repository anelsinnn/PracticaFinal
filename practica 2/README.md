# Generador de Árboles Sintácticos y Gramáticas (CFG)

Aplicación con interfaz gráfica desarrollada para la materia ST0244 - Lenguajes de Programación y Paradigmas de Computación. La herramienta permite estudiar la sintaxis en gramáticas libres de contexto, generando derivaciones paso a paso y construyendo el Árbol de Derivación y el Árbol de Sintaxis Abstracta (AST)[cite: 1].

El proyecto está diseñado en su totalidad aplicando el paradigma de programación orientada a objetos (POO)[cite: 1].
