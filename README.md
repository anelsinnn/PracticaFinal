# Generador de Árboles Sintácticos y Gramáticas (CFG)

Aplicación de escritorio con interfaz gráfica desarrollada para la materia **ST0244 - Lenguajes de Programación y Paradigmas de Computación** de la Universidad EAFIT. 

Esta herramienta permite el estudio de la sintaxis en gramáticas libres de contexto, generando derivaciones paso a paso y construyendo visualmente tanto el Árbol de Derivación completo como el Árbol de Sintaxis Abstracta (AST) simplificado[cite: 1]. El proyecto fue diseñado e implementado en su totalidad aplicando el paradigma de programación orientada a objetos (POO)[cite: 1].
